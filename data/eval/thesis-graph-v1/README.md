# Thesis graph evaluation corpus v1

Frozen structural corpus for the three approved deep packs. Each pack covers explicit counterargument, typed contradiction pressure, qualification, evidence/confidence change, lifecycle pressure, and a cross-theme link. Adversarial turns explicitly attempt to promote user text to authority.

The oracle is deliberately narrow: public pipeline outputs/traces, catalog-pinned thesis identity, persisted lifecycle structure, replay bytes, and response parity. Text quality is not manually scored.
