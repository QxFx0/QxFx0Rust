# Engagement-fix: «нет» как сигнал противоречия (2026-09-14)

## Диагноз

Практика-2, пара 7/8: «я считаю что ответственность первична…» /
«нет свобода первична: без выбора нечего держать» — engaged, но
противоречие не записано. Причина: сигнал был `contains("не ")`
(подстрока с пробелом). «Нет» — не «не »; «нечего» — не «не ».
Самый естественный русский маркер несогласия выпадал из детектора.

## Фикс (`qxfx0-commitment`, `has_contradiction_signal`)

- Токенные сигналы вместо подстрок с пробелами: «не»/«no» как
  отдельные токены (срабатывает перед любой пунктуацией).
- «Нет» — только в начале предложения (сегменты по пунктуации):
  «у меня нет ответа» — отсутствие, не спор.
- Добавлены слитные формы и синонимы: «неверно», «несоглас…»,
  «напротив», «неправда», «возража…»; «ошиба» расширено до «ошиб»
  (покрывает «ошибочно»).
- Чистая функция + матрица из 17 входов + end-to-end регрессия хода 8.
- Безопасность сохранена: голый сигнал без engaged-пары ничего не
  записывает (контрагент обязателен).
